# 🧚 伴游精灵 · AI 防坑旅行管家

一款「大学生特种兵」专属 AI 旅行助手：集**行程定制、防坑避雷、应急求助与极简算账**于一体。

🔗 **在线体验**：https://chris-klay.github.io/trae-hackthon/

> 纯前端单页应用，无需注册、无需后端。未配置 API Key 也能体验完整流程（自动走免费模型 / 本地演示数据降级）。

## 功能一览

| 阶段 | 功能 | 说明 |
|---|---|---|
| 行前 | ✨ 智能行程规划 | 大白话输入（"去南昌玩2天，预算500，爱吃辣，不想人挤人"）→ AI 生成带时间轴的避峰行程，景点标记+连线自动上地图 |
| 行前 | 🌤️ 天气穿搭提醒 | 自动抓目的地未来 3 天天气，温馨口吻提醒带伞/添衣/防滑 |
| 行中 | 📸 拍照识坑 | 拍景区特产/菜单 → 多模态大模型识别 → 估价并提示是否"大冤种" |
| 行中 | 🎤 语音排雷 | 按住说话"这家店靠谱吗" → AI 朋友口吻给排雷建议 |
| 行中 | 🆘 突发百事通 | "我吃海鲜过敏了" → 分级处置指南 + 120/110/12345 一键拨打 |
| 财务 | 🧮 AA 算账 + 物价鉴定 | "打车50吃饭120，3人AA" 一句话出人均；"银镯子2000" 鉴定是否被宰 |
| 安全 | 🎒 紧急安全备忘卡 | 悬浮红按钮随时点开，血型/过敏史/紧急联系人全屏大字，可直接给医生看 |

## 技术栈

- **前端**：原生 ES Module + Vite（单文件构建，vite-plugin-singlefile）
- **地图**：腾讯地图 GL JS（GCJ-02 坐标系，景点标注/编号/箭头路线）
- **LLM**：OpenAI 兼容接口，默认阿里百炼（qwen-plus / qwen-vl-plus）；支持任意兼容端点，Key 存浏览器本地
- **天气**：wttr.in 主源 + Open-Meteo 备源（双源自动切换）
- **部署**：GitHub Pages

## 韧性设计（无 Key / 弱网也能演示）

1. 配置了 API Key → 官方接口实时生成
2. 未配置 → 免费模型接口兜底
3. 接口不可达 → 本地演示数据兜底（按输入关键词匹配城市），30 秒内必出结果

## 本地开发

```bash
cd travel-buddy      # 源码目录（本仓库为构建产物）
npm install
npm run dev          # http://localhost:5173
npm run build        # 构建单文件 dist/index.html
```
